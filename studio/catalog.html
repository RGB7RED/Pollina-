Загрузка моделей… Принято ≠ готово к релизу

В этой папке пока нет моделей с такими параметрами.

№ 001 в папке «Здания» и № 001 в папке «Персонажи» — разные модели. Например, 22 дерева на улице — это 22 экземпляра одной модели дерева № 001, а не 22 уникальные модели. Когда создадим новое дерево с другим внешним видом, оно получит № 002.

🟢 «Принят для лаборатории» — не готовность к релизу. Сторонние GLB требуют проверки происхождения и прав.

Новые объекты регистрируются через models/catalog.json в GitHub после разработки в отдельной лаборатории. На этой странице нет кнопки редактирования проекта: статусы и файлы не изменяются без новой проверенной версии в Git.
