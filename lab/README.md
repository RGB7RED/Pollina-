# MINI CITY — каталог 3D-лабораторий

**Открой `lab/index.html`**, чтобы выбрать дом или персонажа. В любом просмотрщике есть две ссылки: «Дом» и «Персонаж». Ссылки `../building-lab/index.html` и `../character-lab/index.html` **относительные**, поэтому работают как в GitHub Pages, так и в закреплённой ссылке rawcdn.githack.com на коммит/ветку.

При переключении загружается **другая самостоятельная сцена**: камера и состояние анимаций при переходе не сохраняются. Цель — удобная лаборатория объектов, не общая игровая сцена.

Дом строится из исходника `building-lab/building.js`, авторские материалы — в `building-lab/materials.js`. Кнопка «↓ Скачать GLB» выдаёт переносимый `apartment_house.glb` (генератор в `building-lab/export-glb.js`). Готовый бинарник **пока не добавлен в GitHub**: создаётся в браузере при скачивании. Мировые UV кирпича конвертируются в обычные glTF UV, остальные детали передаются через instancing. Для сторонних движков нужно протестировать поддержку `EXT_mesh_gpu_instancing`.

Анатомическая база `character-lab/assets/hero-reference.glb` находится в репозитории, но **не имеет анимаций**. Внешний анимированный кандидат загружается по фиксированному URL и не включён в файлы игры. Перед релизом требуется независимая проверка происхождения файла.

Не менять `main` и не объединять эти лаборатории с городом без отдельной команды владельца. Визуальная проверка генерации GLB и FPS после импорта обязательна.
