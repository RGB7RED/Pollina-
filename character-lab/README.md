# MINI CITY 0.3.3 — этап 1: лаборатория персонажа

## Что сделано

Мы прекратили имитировать людей набором `SphereGeometry` / `CylinderGeometry` в `game.js` и впервые загрузили **реальный внешний художественный 3D-ассет в бинарном формате GLB** в отдельной тестовой сцене.

**Это самостоятельная проверочная сцена, не новая версия города.** Ветки с игрой (`main`, `feat/mini-city-v032`) не менялись.

### Как посмотреть на iPhone 12

Открой `character-lab/index.html` через HTTPS-публикацию ветки `feat/mini-city-v033-character-lab` (например, URL rawcdn.githack.com с конкретным SHA + `/character-lab/index.html`).

В лаборатории:
- «Городской (внешний)» — **внешний сравнительный кандидат** с одеждой (`CasualCharacter.glb`). Файл **не** внесён в репозиторий; загрузка и внешний CORS требуют проверки в Safari.
- «Анатомическая база CC0» — сохранённый в этом репозитории лицензированный GLB (`hero-reference.glb`), работает как офлайн-относительный ассет после первоначальной загрузки Three.js.
- Свайп / щипок — вращение и масштабирование.
- «Скелет» — визуализация реальных костей.
- «Проверить суставы» — встроенная анимация модели, если она есть; иначе временное процедурное тестовое движение **существующих костей**, не финальная походка.

### Проверенная локальная модель

- Автор: Quaternius, пакет Universal Base Characters [Standard], модель Superhero Male.
- Источник промежуточной сборки GLB: `programasweights/avatar/public/assets/character.glb` (SHA: `b3fd79533fdb9fcedd077744f7e120920eb6cc97`).
- Лицензия CC0-1.0. Подлинный `QUATERNIUS-LICENSE.txt` сохранён рядом.
- Размер: 741 320 байт.
- Формат: glTF 2.0 (GLB).
- Геометрия: 3 mesh, 8 483 вершины.
- Скелет: 65 суставов, настоящие `JOINTS_0 / WEIGHTS_0`.
- Встроенных анимационных клипов: **0**.

**Это анатомическая база, не подходящий готовый герой для петербургской игры!** У базового GLB нет отдельной куртки, причёски и полноценных анимаций. Следовательно, **художественный этап 1 нельзя считать принятым только по техническим проверкам**.

### Внешний городской кандидат

Для сравнения временно подключена открытая модель `CasualCharacter.glb` через фиксированный коммит другого GitHub-репозитория. Quaternius публиковал Casual Character под CC0 (см. https://poly.pizza/m/kZ3DmIoGip), однако **тождество зеркального GLB официальному исходнику не подтверждено**; права на конкретные байты зеркала ещё нужно проверить перед переносом в игру или репозиторий. Если она не загружается, автоматически используется локальная CC0-модель.

Это означает: на этапе 1 **оцениваем прежде всего качество силуэта, лица, одежды и работу скелета на телефоне**; ни один кандидат пока не утверждён героем.

## Жёсткие критерии принятия этапа 1

1. Есть **выбранная пользователем** модель с подходящей художественной стилизацией (не Roblox и не обнажённая заготовка).
2. Происхождение и лицензия **именно выбранного** ассета подтверждены, а файл хранится в нашем проекте.
3. Модель риггирована, корректно деформируется и готова к ретаргетингу настоящих анимаций.
4. Показывается с пяти ракурсов без визуальных дефектов на iPhone 12.
5. FPS и размер ресурсов устраивают пользователя в отдельной сцене.
6. Только после этого начнётся следующий этап — анимации и интеграция в существующую игру.

## Проверки

```bash
node --check character-lab/lab.js
node character-lab/test-model.mjs
node character-lab/test-ui.mjs
```

`test-model.mjs` проверяет сам бинарный файл, магию GLB, скелет и бюджет размера. Это **не** WebGL/Safari-тест. GitHub Actions в прошлых ветках не получал runner, поэтому отсутствие красного статуса CI не является доказательством готовности.
