# MINI CITY — Автобусная остановка №003 (этап 4.3.1A)

Отдельный процедурный прототип для визуальной приёмки. **В игровой сцене объект не установлен.**

**Открыть:** Developer Studio → Каталог объектов → Городские предметы → №003 → «Осмотреть остановку». Из лаборатории есть прямая ссылка обратно в папку «Городские предметы». При открытии через закреплённый rawcdn.githack SHA относительные ссылки удерживают этот SHA.

**Камера:** на iPhone один палец вращает объект, два пальца перемещают/масштабируют; на ПК мышь/колесо. Есть ракурсы ¾, спереди, сбоку, крыша, кнопки сброса и день/вечер. Панель отображает фактический FPS и `renderer.info.render` для **всей сцены**, отдельно — число треугольников и материалов модели.

**Геометрия:** начало координат в центре павильона на земле; вход — по оси +Z. Основная конструкция шириной 4,2 м и глубиной 1,8 м, изогнутая крыша до 2,72 м, высота знака 3,5 м, сиденье 0,45 м. Полный габарит со знаком шире павильона. Шесть логических групп: Structure, Roof, GlassPanels, Bench, BusSign, InformationBoard. Стекло альфа-прозрачное, мелкие элементы собраны через InstancedMesh. Текстуры знака и маршрутов генерируются на месте из Canvas — внешних ассетов нет.

**Автотесты:** `node bus-stop-lab/test-bus-stop.mjs` проверяет функциональное построение с заглушками API Three.js, архитектуру, прозрачность, координаты и геометрический бюджет; `node bus-stop-lab/test-viewer.mjs` проверяет разметку, проводку камеры и каталог. Также запускаются существующие тесты реестра и DOM-каталога.

**Ограничения:** поддельный Three API не заменяет реальный WebGL. Работа в iPhone Safari, кадровая частота на устройстве и визуальное сходство с фотографией требуют ручной проверки пользователем. CI из предыдущей ветки падал до старта тестовых шагов, поэтому успешная проверка GitHub Actions не предполагается без фактического завершения workflow. Переход к интеграции в игровую лабораторию и коллизиям — только после визуального одобрения.

Не сливать без отдельной команды «Сливай».
