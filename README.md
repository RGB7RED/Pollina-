# РАЙОН · MINI CITY 0.2.1 — оптимизация

**Цель этой версии:** улучшить производительность на iPhone 12 без изменения привычного управления и без увеличения карты. Следующее обновление 0.3 будет посвящено подъездам и взаимодействиям.

## Запуск

Исходники 0.2.1 находятся в ветке **feat/mini-city-v021** (отделена от v0.2, в main не объединена).

- Временно протестировать можно по ссылке rawcdn.githack.com с SHA коммита ветки. Этот адрес привязан к конкретному коммиту и никогда не обновляется автоматически.
- Чтобы разместить игру постоянно: GitHub → Settings → Pages → Deploy from a branch → feat/mini-city-v021 → /(root) → Save. Ожидаемый URL после успешного деплоя: https://rgb7red.github.io/Pollina-/.
- Для Three.js используется CDN jsDelivr. Нужен доступ к интернету.

## Изменения 0.2.1

- **Батчинг статических поверхностей:** тротуары, асфальт, разметка, площадки и покрытия больше не создают отдельный WebGL draw call на каждую полоску. Они объединяются в InstancedMesh по материалам.
- **Батчинг межэтажных поясов зданий:** многие повторяющиеся декоративные элементы используют существующий instanced-рендер.
- **Отсечение невидимых объектов:** дальние деревья, скамейки, фонари и припаркованные машины отключаются; геометрия остаётся в мире, не меняя игровые координаты.
- **Тени:** теневая область следует за игроком, вместо того чтобы всегда оставаться в центре карты; размер области уменьшен для большей плотности карты теней.
- **Ночное освещение:** вместо всех точечных ламп одновременно освещают сцену только до четырёх ближайших фонарей. Светящиеся детали фонарей видны везде.
- **Отсечение instanced-объектов:** вычисляется ограничивающая сфера вместо постоянного принудительного рисования.
- **Отладка:** вверху показаны FPS, число вызовов рендера, число треугольников и масштаб разрешения. Это показатели текущего кадра, а не доказательство стабильной производительности.
- **Интерфейс:** убрана назойливая подсказка «поверни телефон», уведомления расположены отдельно от верхней панели.
- **Управление:** левый стик, жесты камеры, прыжок и бег не переназначались; поведение персонажа сохранено.

## Как проверить на iPhone 12

1. Открыть 0.2.1 в Safari, дождаться полной загрузки сцены и сделать скриншот в той же точке и с тем же ракурсом, что в 0.2.
2. Подвигаться по главной улице 30–60 секунд. Записать диапазон FPS, число рисований (рис.), наличие подвисаний.
3. Проверить поведение при переключении на ночь. На экране не должно быть сильного падения FPS от одновременного включения десятков источников света.
4. Проверить поворот камеры, движение джойстиком, посадку в машину, отображение вывески, мини-карту, смену дня и ночи, поиск трёх точек.
5. Проверить горизонтальный и вертикальный экран, убедиться, что уведомление не перекрывает верхний HUD.

**Критерий дальнейшего шага:** нет регрессий управления и графики, FPS предпочтительно ≥30 при прогулке на iPhone 12. Измерить реальный результат без устройства невозможно.
