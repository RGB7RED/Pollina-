# РАЙОН · Mini City v0.2

**Мобильная 3D-игра для iPhone 12** в стилистике low-poly Санкт-Петербурга: небольшая прогулка от третьего лица по открытой карте. Работает в браузере без Railway и бэкенда.

## Запуск в Safari

Код версии 0.2 находится в **ветке feat/mini-city-v02**, пока не объединён с main.

Самый простой способ временно открыть текущую версию для тестирования — rawcdn.githack.com с конкретным SHA коммита и /index.html. После каждого обновления ветки ссылка на старый SHA продолжает показывать старую версию.

Для постоянной публикации в GitHub Pages:
1. GitHub → Settings → Pages.
2. Build and deployment → Deploy from a branch.
3. Выбрать feat/mini-city-v02 и /(root), сохранить.
4. После публикации открыть https://rgb7red.github.io/Pollina-/ (ожидаемый адрес, наличие страницы нужно проверить).

Игра использует Three.js 0.170.0 с jsDelivr, поэтому при первом запуске нужен интернет.

## Управление

- Левый джойстик — ходить; БЕГ — удерживать; ПРЫЖОК — прыгать.
- Свайп по 3D-миру — вращать камеру; щипок двумя пальцами — приближать/отдалять.
- ДЕЙСТВИЕ — взаимодействовать рядом с объектом (машина, дверь магазина).
- В правом верхнем углу — смена времени суток и переключатель звуков.
- ПК: WASD, Shift, Space, E, вращение мышью, колёсико для масштабирования.

В левом верхнем углу показывается FPS для проверки производительности. Качество рендера может немного снижаться при устойчиво низкой частоте кадров.

## В v0.2 добавлено

- Площадь мира увеличена примерно в 3.8 раза, до квадратной территории 328×328 игровых единиц: сетка из девяти перекрёстков.
- 24 дополнительных здания в новых кварталах, фасады с карнизами, балконами, декором, арками, двориками, фонарями и озеленением.
- Дополнительные NPC (всего 17) с короткими остановками на маршрутах и отключением анимации вдали от игрока.
- Новая low-poly модель героя с более пропорциональной головой, более чёткими деталями одежды и рюкзаком.
- Плавные ускорение и торможение, переделанное управление камерой и щипок для изменения дистанции.
- Переделанные HUD и кнопки для вертикального и горизонтального экранов.
- Исправленные двусторонние надписи на вывесках.
- Мини-карта следует за героем; карта пригодна для расширения.
- Статические детали зданий объединены в instanced draw calls ради производительности iPhone.
- Счётчик FPS и осторожная адаптация разрешения рендеринга.

## Пока не реализовано

- Поиск тайников, фотографии/координаты и игровой телефон: разработаем на следующих этапах.
- Реакция и шкалы подозрений NPC, полиция и система розыска.
- Передвижение автомобилей (в v0.2 они припаркованы).
- Доступные интерьеры подъездов, полноценная физика предметов.
- Миссии и игра по главной концепции.

Игра пока сохраняет старый тестовый квест: найти магазин, остановку и двор.

Фактический FPS и визуальное качество v0.2 на iPhone 12 необходимо проверить на устройстве; успешность тестирования пока не подтверждена.

## Структура

- index.html — интерфейс, стили, мобильная адаптация.
- game.js — сцена, персонаж, камера, движение, AI пешеходов, управление и аудио.
- district.js — генерация новых кварталов и декора главного района.
- test/smoke.mjs — статические проверки.
- .github/workflows/mini-city.yml — проверки GitHub Actions.

## Проверка

    node --check game.js
    node --check district.js
    node test/smoke.mjs

GitHub Actions в предыдущей версии завершался со статусом failure без запущенных шагов и без назначенного runner; это не является подтверждением ошибки игры. Проверка кода локальным Node и реальное тестирование на iPhone — отдельные проверки.
