# РАЙОН · Mini City (v0.1)

Небольшая браузерная 3D-игра для **iPhone 12**: прогулка от третьего лица по стилизованному городскому кварталу. Без Railway, сервера, сборщика и платных зависимостей.

## Как запустить

В GitHub открой **Settings → Pages → Build and deployment → Deploy from a branch**; выбери ветку **feat/mini-city-v1** и папку **/(root)**, затем **Save**. После успешной публикации сайт будет доступен по ожидаемому адресу:

**https://rgb7red.github.io/Pollina-/**

> Адрес приведён как ожидаемый, а не подтверждённый. Если в настройках Pages выбран другой источник публикации, ветка не будет опубликована автоматически.

Открой страницу в Safari на iPhone 12 и нажми «Начать прогулку». Для удобства поверни телефон горизонтально. Для импорта Three.js нужен интернет (CDN).

## Управление

| iPhone | ПК |
| --- | --- |
| Стик слева — ходьба | W/A/S/D — движение |
| Свайп по миру — поворот камеры | Зажать мышь и двигать — камера |
| БЕГ — удерживать | Shift |
| ПРЫЖОК | Пробел |
| ДЕЙСТВИЕ, если доступно | E |
| Время суток, звук — справа сверху | Те же кнопки |

## Что реализовано

- Процедурно построенные улицы и перекрёсток, многоквартирные здания, окна, деревья, фонари, дорожная разметка, светофоры, дорожные знаки, скамейки, магазин, остановка, автомобили.
- Мультяшный персонаж со стилизованными анимациями ходьбы и бега, прыжком и базовыми столкновениями со зданиями и припаркованными машинами.
- Камера от третьего лица, сенсорный джойстик и кнопки для телефона.
- Пять прохожих на маршрутах.
- Четыре режима времени суток; светящиеся фонари в ночном режиме.
- Посадка в припаркованную машину (без вождения) и открывание двери магазина (декоративное, интерьер пока отсутствует).
- Задание на исследование: магазин, остановка и двор. Мини-карта.
- Генерируемые браузером простые звуки шагов, шум города и фоновая мелодия с переключателем.

## Ограничения v0.1

Это **первый тестовый прототип**, а не завершённая GTA. NPC не разговаривают, машины не ездят, в здания нельзя войти, сложного транспорта и заданий нет. Графика геометрическая; вместо детальных персонажей используются процедурные модели. Аудио синтезируется через Web Audio.

Целевые 30 FPS на iPhone 12 — **ориентир**, фактическую производительность ещё нужно проверить на устройстве. Реальная браузерная проверка на iPhone не проводилась.

## Технологии

- HTML, CSS, JavaScript ES modules.
- Three.js 0.170.0, подгружаемый с jsDelivr.
- GitHub Pages для размещения.

## Разработка и проверка

Сайт состоит из index.html и game.js. Запускать через HTTP(S), не через открытие локального файла (ES modules и CDN).

Статические проверки:

    node --check game.js
    node test/smoke.mjs

Файлы игры публикуются в отдельной ветке. Изменения в main попадут только после отдельного разрешения на объединение.
