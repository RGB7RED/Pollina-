# MINI CITY · 0.3.2 — Graphic Rework

**Цель:** уйти от грубых Roblox-подобных фигур к самостоятельной художественной подаче, вдохновлённой **Road 96**: холодный стилизованный городской мир, рисованная атмосфера, более взрослые персонажи и современный мобильный интерфейс. Это **не** воспроизведение графики Road 96 и **не** использование её ресурсов.

### Как проверить

Код находится в ветке `feat/mini-city-v032`, основанной на версии `feat/mini-city-v031`. Версии 0.3.1 и предыдущие не удалены, `main` не изменён.

Для предварительного просмотра на iPhone 12:
- Открыть файл `index.html` из конкретного SHA коммита через rawcdn.githack.com. Ссылка с хешем показывает фиксированную версию.
- Альтернатива: включить GitHub Pages для `feat/mini-city-v032` (root) в Settings → Pages и использовать ожидаемый адрес `https://rgb7red.github.io/Pollina-/` после успешного деплоя.
- Внешние запросы — только Three.js с CDN. Railway не требуется.

### Что действительно изменено

- **Персонажи:** вместо блоков — общая рисованно-стилизованная модель из округлых и сужающихся форм: корпус, лицо, нос, волосы, уши, одежда, конечности с подвижными коленями и локтями. Восемь вариантов палитры одежды. Персонажи всё ещё **процедурные**, не готовые 3D-ассеты из профессионального пайплайна.
- **Небо:** панорамный текстурный купол с градиентами и нарисованными слоистыми облаками. День, утро, вечер, ночь — разные оттенки.
- **Окна:** рисованные отражения, переплёты, шторы и светящиеся окна вместо полностью тёмных прямоугольников.
- **Улицы:** оптимизированные пятна влаги и следы износа дороги (130 объектов в **одном** InstancedMesh), без внешних изображений.
- **Деревья:** несколько несимметричных гранёных лиственных масс на ветвистом стволе вместо «леденцов на палочке».
- **Камера:** мягче следует за героем, изначальная дистанция немного ближе, щипок масштаба работает как прежде.
- **Интерфейс:** панель заданий, кнопки, цвет, заставка и мини-карта в единой холодной кинематографичной палитре.

### Что оставлено без изменений

- Размер и расположение улиц, внутренняя структура трёх подъездов, управление и логика лестниц.
- Посадка на скамейку, NPC, исследование района, звук, цикл дня и ночи, графические пресеты.
- Система тайников, внутриигровой смартфон и полиция пока не реализованы.

### Тестирование

Статические проверки и контрактные Node-тесты:

```sh
node --check game.js
node --check characters.js
node --check visuals.js
node --check art_direction.js
node test/smoke.mjs
node test/remaster.mjs
node test/runtime.mjs
node test/performance.mjs
node test/interiors.mjs
```

`test/runtime.mjs` выполняет игру с имитацией Three.js/DOM, **не** в настоящем Safari/WebGL. Тесты не доказывают визуальное качество, а FPS на iPhone после редизайна пока не подтверждён.

Что проверить на телефоне: герой сбоку/спереди/сзади, облака и рассвет/вечер, текстуры окон, деревья, дальние дома, подъём в подъезде, скамейка, 3 графических режима, FPS и отсутствие ошибок.

**Ограничения:** у нас по-прежнему нет полноценного производства 3D-ассетов, UV-текстурирования и продвинутой анимации. Для дальнейшего качественного приближения к Road 96 потребуется отдельный этап с художественными моделями и анимациями. Этот релиз делает конкретный переход в выбранную стилизацию, но не гарантирует «визуально как Road 96».

**DO NOT MERGE** до отдельной команды «Сливай».
