# РАЙОН · MINI CITY 0.3.1 — VISUAL REMASTER

Браузерный 3D-прототип для iPhone 12 без Railway, API-сервера и сборщика. Three.js 0.170.0 подгружается через CDN. Город стилизован под пасмурный петербургский спальный район, с художественным ориентиром между GTA San Andreas и GTA IV. Это оригинальная упрощённая графика, а не уровень графики GTA IV.

**Ветка обновления:** feat/mini-city-v031, ответвление от 0.3.
**main не изменяется** до команды «Сливай».

## Изменения 0.3.1

### Новый визуальный стиль
- Приглушённое пасмурное освещение, серо-зелёная палитра фасадов и дорог, менее яркие режимы времени суток.
- Процедурные текстуры для штукатурки панельных зданий, асфальта, плитки и газонов. Не требуют скачивания внешних текстур.
- Гаражные боксы, дворовые ограждения, контейнеры, дополнительные бетонные детали.
- Карта остаётся 328×328 игровых единиц, новые кварталы не добавляются.

### Человек вместо блочной фигурки
- Новый пропорциональный low-poly персонаж с округлой головой и сегментированными руками/ногами.
- Восемь сочетаний одежды/оттенков и небольшие вариации роста у жителей.
- Общие геометрии и кэш материалов между моделями. Кнопки управления не изменены.

### Исправленная скамейка
- Плавный подход к месту посадки и поворот корпуса.
- Анимация сгибания бёдер и коленей, переход между ходьбой, сидением и стоянием.
- Кнопка ДЕЙСТВИЕ позволяет сесть/встать. Скамейки, занятые NPC, пока недоступны игроку.

### Три многоэтажных подъезда
- Три здания имеют пять, пять и три этажа.
- Два лестничных марша на каждый переход между этажами, ступени, перила и межэтажные площадки.
- Реальное изменение высоты при ходьбе по лестницам, без телепорта между этажами.
- Двери квартир и окна на этажах; почтовые ящики на первом.
- Камера следует за высотой персонажа; выход во двор расположен на первом этаже.
- Схема помещения на мини-карте и сохранение посещений в localStorage при доступности.
- Статические элементы подъездов объединены в InstancedMesh. Неактивные подъезды скрыты.

### Графические настройки

| Качество | Разрешение | Тени | Ночные фонари | Дальность NPC |
| --- | --- | --- | --- | --- |
| Низкое | до 0.9× | Выкл | 2 | 43 ед. |
| Среднее | до 1.15× | Вкл | 3 | 67 ед. |
| Высокое | до 1.55× | Вкл | 4 | 86 ед. |

Кнопка ⚙ справа вверху меняет качество. Настройка сохраняется в браузере, если доступен localStorage. Автоматическое уменьшение разрешения при просадках FPS остаётся включённым. Значения FPS не гарантируются.

## Что осталось

- Модели города всё ещё процедурные. Для уровня коммерческой графики потребуются отдельные 3D-ассеты и текстурные атласы.
- Квартиры недоступны; подъезды построены по повторяющейся схеме, отличаются этажностью и оформлением.
- Нет движения автомобилей, сложных расписаний NPC, системы подозрений и полиции.
- Смартфон персонажа, фотографии и координаты, тайники — следующая версия 0.4 и далее.

## Запуск

Временная ссылка для игры строится через rawcdn.githack.com с конкретным SHA коммита ветки feat/mini-city-v031. Этот адрес не обновляется после новых коммитов.

Для постоянной публикации: GitHub → Settings → Pages → Deploy from a branch → feat/mini-city-v031 → /(root) → Save. После успешной публикации ожидается https://rgb7red.github.io/Pollina-/.

## План проверки на iPhone 12

1. Посмотри пасмурный город, вечер и ночь. Оцени внешний вид персонажа и зданий.
2. Через кнопку ⚙ последовательно проверь низкое, среднее и высокое качество. Запиши FPS. Версия 0.3 ранее показывала 58–60 FPS, результат 0.3.1 ещё неизвестен.
3. Найди подъезд №1, войди, поднимись по обеим лестничным секциям на 2-й и 3-й этаж. Спустись пешком и выйди.
4. Проверь подъезд №3: три этажа, подъём не должен продолжаться выше последней площадки.
5. Сядь на свободную скамейку, проверь положение ног и корпуса, затем встань.
6. Проверь NPC, мини-карту, камеру, звуки, смену времени суток, старые точки исследования и посадку в машину.
7. Проверь вертикальное и горизонтальное положение iPhone.

## Файлы и проверки

- game.js — сцена, управление, NPC, время суток, настройки качества.
- district.js — кварталы и дворики.
- interiors.js — геометрия и логика лестниц.
- characters.js — новые модели людей и позы.
- visuals.js — процедурные материалы.
- test/smoke.mjs — проверка связности файлов и синтаксиса.
- test/interiors.mjs — проверка непрерывного маршрута 3/5 этажей.
- test/performance.mjs — батчинг и бюджет фонарей.
- test/remaster.mjs — риг персонажа и материалы.
- test/runtime.mjs — запускает настоящий код игры с заменителями Three.js/DOM.

Проверки запускаются Node 22:

    node --check game.js
    node --check district.js
    node --check interiors.js
    node --check characters.js
    node --check visuals.js
    node test/smoke.mjs
    node test/interiors.mjs
    node test/performance.mjs
    node test/remaster.mjs
    node test/runtime.mjs

Тесты с заглушками не являются настоящим Safari/WebGL e2e. Фактическую графику и FPS версии 0.3.1 на iPhone ещё нужно проверить.

Исторически GitHub Actions завершался без назначения runner и без выполнения шагов. Его статус не следует путать с проверкой игрового кода.
