# РАЙОН · MINI CITY v0.3 — первые игровые взаимодействия

Браузерная мобильная 3D-игра, разработанная прежде всего для iPhone 12. Район стилизован под Петербург. Игровой мир запускается без Railway и сервера, с загрузкой Three.js через интернет.

Ветку **feat/mini-city-v03** создали на основе проверенной на iPhone 12 версии **0.2.1**. Основная ветка main не менялась. Никаких слияний без отдельной команды «Сливай».

## Новое в 0.3

**Доступные подъезды:**
- Добавлены 3 отмеченных голубыми символами на мини-карте подъезда рядом с жилыми домами.
- Подойди к синему входу и нажми «ДЕЙСТВИЕ» — персонаж перейдёт внутрь подъезда.
- У каждого подъезда есть небольшое проходимое помещение первого этажа: лестница, почтовые ящики, двери квартир, указатели, свет.
- Внутри можно ходить и осматривать ящики кнопкой действия. Чтобы выйти, вернись к двери «ВЫХОД» и нажми «ДЕЙСТВИЕ».
- Учёт открытых подъездов 0/3 показывается под старым заданием «найти 3 места». Посещения сохраняются в локальном хранилище браузера, когда оно доступно.
- Верхний индикатор показывает, где сейчас персонаж. Внутри мини-карта переходит в схему комнаты.

**Повседневные NPC:**
- 2 жителя отдыхают на скамейках, остальные 15 ходят по тротуарам и иногда задерживаются на остановках своих маршрутов.
- Отдыхающие могут повернуться к подошедшему игроку, другие во время паузы могут наблюдать за прохожим.
- Шкалы подозрений, диалоги, распорядок по часам и полицейские пока **не реализованы**.

**Интерактивные скамейки:**
- Подойди к скамейке → «ДЕЙСТВИЕ» → персонаж садится.
- Кнопка действия или прыжок позволяют встать.

**Производительность:**
- Карта остаётся прежней: 328×328 игровых единиц, без дополнительных домов за пределами текущих районов.
- Снаружи интерьеры скрыты из рендера, внутри выключена большая внешняя сцена; одновременно отображается только одна комната.
- Сохранена оптимизация v0.2.1: InstancedMesh для дорог, отсечение дальних объектов, ограниченные динамические фонари и счётчик FPS.
- Условная цель — сохранить плавную работу и ~60 FPS на iPhone 12; реальный FPS 0.3 ещё не подтверждён.

## Управление

- iPhone: стик слева — ходьба, «БЕГ» — удерживать, «ПРЫЖОК» — прыгать, «ДЕЙСТВИЕ» — войти, выйти, сесть, встать или осмотреть предмет.
- Свайп по игровому миру вращает камеру, жест двумя пальцами меняет расстояние.
- ПК: WASD, Shift, пробел, E; мышь и колёсико для камеры.
- Слева отображается FPS, рисования (draw calls), треугольники, множитель разрешения.

## Быстрый тест на телефоне

1. Открой версию 0.3 по ссылке конкретного коммита на rawcdn.githack.com. Поверни экран горизонтально для большего обзора.
2. Убедись, что движение, камера и частота кадров не ухудшились относительно 0.2.1 (ты сообщал 60 FPS).
3. Найди голубой квадрат на мини-карте, подойди к подъезду, нажми «ДЕЙСТВИЕ».
4. Осмотри почтовые ящики, вернись к двери, выйди во двор. Счётчик «Подъезды» должен увеличиться.
5. Найди скамейку, сядь и встань. Проверь, что управление не застревает и камера не выходит сквозь стены помещения.
6. Проверь смену времени суток, посадку в стоящую машину и старые 3 точки исследования.

## Ограничения

- Подъезды имеют похожую планировку **только первого этажа**. Подняться по лестнице или войти в квартиры пока нельзя; переход внутрь делается через кнопку взаимодействия, а не через физически непрерывный проход.
- Почтовые ящики пока осматриваются без сбора предметов.
- Автомобили по-прежнему припаркованы, интерьеры магазинов закрыты.
- Внутриигровой телефон, фотографии, тайники, шкалы подозрений NPC, полиция и полноценная физика предметов — дальнейшие этапы.
- Никакие настоящие координаты тайников или незаконные предметы игра не использует.

## Структура репозитория

- index.html — адаптивный интерфейс.
- game.js — рендер, управление, сцены, взаимодействия, персонаж и NPC.
- district.js — внешние кварталы, фасады и окружение.
- interiors.js — три подъезда, ограничения передвижения и зоны взаимодействия.
- test/smoke.mjs — статические проверки.
- test/interiors.mjs — контрактные тесты подъездов.
- test/performance.mjs — регрессионные тесты batching/освещения.
- .github/workflows/mini-city.yml — GitHub Actions (исторически runner недоступен; статус проверять отдельно).
